Installing takes a minute

Arcky is a test build, so it isn't notarized by Apple yet. macOS asks you to approve it once.

Download

Get Arcky.dmg and open it.

Drag to Applications

Drop Arcky onto the Applications folder in the window that opens.

Open it once

macOS will say it can't verify Arcky. Click Done, not Move to Trash.

Approve

In System Settings ▸ Privacy & Security, scroll down and click Open Anyway.

Comfortable with Terminal? This does steps 3 and 4 in one go: xattr -dr com.apple.quarantine /Applications/Arcky.app

Questions

The short answers.

Is this Arc?

No. Arcky is an independent project inspired by Arc's ideas. It isn't affiliated with or endorsed by The Browser Company.

Why does macOS warn me about it?

Apps from outside the App Store need to be notarized with a paid Apple developer account for macOS to recognise them. This test build isn't, so you approve it once by hand (see Install).

Where is my data kept?

On your Mac. If you turn on Sync, Arcky also keeps a copy in your own iCloud Drive (or a folder you choose). Nothing is sent anywhere else.

Do Chrome extensions work?

Not yet. Arcky uses Apple's WebKit engine (like Safari), which keeps it light but doesn't run Chrome extensions. Boosts and built-in blocking cover the common cases.

Which Macs can run it?

Any Mac with macOS 15 Sequoia or later, Apple Silicon or Intel.

Found a bug?

Tell whoever sent you Arcky, or open an issue on GitHub. Thank you for testing!

Ready to try it?

It's free, small (under 5 MB) and takes a minute to set up.
